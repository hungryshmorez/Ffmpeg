# Repository guide

This repo holds two separate projects:

* **FFmpeg Studio** — the original browser app (root-level `*.js`, `index.html`). Not under active development.
* **FFWORKS** — a native Windows-first editor (Rust engine + Tauri + React) in `ffworks/`. **This is the active project.**
  **Before doing anything on FFWORKS, read `ffworks/CLAUDE.md` and `ffworks/docs/STATUS.md`.**
